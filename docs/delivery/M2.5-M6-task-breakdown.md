# M2.5-M6 产品演进任务清单

> 状态：M2.5 已完成；M3-M6 已规划，未启动。
> 基线：M1、M2、即时聊天和 M2.5 已完成；任何后续任务不得破坏既有发布、互动、通知、治理和聊天 E2E。

## 共同门禁

- 每项任务均需设计说明、数据库迁移（如适用）、后端、博客端、管理端、自动化测试与交付记录。
- MySQL 为事实来源；Redis 只能增强，不得让核心流程因 Redis 缺失失效。
- 所有写操作必须有资源级鉴权、幂等处理、审计日志和失败回滚策略。
- 每阶段最后一项为全量验收：Maven、博客端 typecheck/lint/test/build、管理端 typecheck/lint/test/build、迁移校验和真实浏览器 E2E 全部通过。

## 任务状态约定

- `待开发`：仅完成路线和验收定义，不得对外描述为已具备。
- `开发中`：已开始代码与迁移改造，但尚未完成阶段门禁。
- `完成`：已通过共同门禁并在 `development-status.md` 中记录交付证据。
