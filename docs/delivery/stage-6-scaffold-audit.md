# 阶段 6：脚手架保留与扩展审计

审计日期：2026-07-26

## 1. 修订后的决策

阶段 6 原计划删除没有进入社区主业务的脚手架能力。执行到菜单和示例数据清理
后，产品决策调整为：

- 不再删除脚手架模块、源码、管理端页面或依赖，保留为未来扩展方向。
- 未启用的支付、短信、微信、第三方登录、SSH 管理、代码生成和示例能力继续由
  `pxczxn.features.scaffold.*` 默认关闭。
- 不恢复任何历史密钥；集成配置仅保留 `enabled=false` 的无密钥占位。
- 即时聊天不再属于待删除能力，升级为正式模块。
- 评论、动态、通知、内容治理等 M1/M2 社区业务不得因保留策略或聊天开发改变
  既有语义。

阶段 6 不再执行 Maven 模块删除，也不删除三个未进入 Reactor 的旧目录。它们
继续作为明确记录的技术债，不能重新进入运行时或恢复 Mars 品牌。

## 2. 保留能力

- 用户、组织、RBAC 和 Sa-Token 管理员认证。
- 社区独立用户会话和资源级权限检查。
- 文件管理、OSS 抽象和社区文件 20 MB 业务限制。
- Redis 可选增强与 WebSocket Ticket Redis/内存降级。
- Quartz、文章定时发布任务和调度日志。
- 操作日志、登录日志、API 访问日志和审计能力。
- 系统公告、站内通知和即时聊天。
- 邮件、飞书和钉钉通知适配器。
- 支付、微信、短信、第三方登录、代码生成、SSH 管理和示例模块源码。

## 3. 运行时边界

默认关闭且继续受 404 功能边界保护：

- `/api/auth/sms-code`
- `/api/sys/config-group/test-payment`
- `/api/sys/config-group/test-sms`
- `/api/sys/config-group/sms-logs/**`
- `/api/wechat/**`
- `/api/monitor/server-manager/**`
- `/api/tool/gen/**`
- `/api/system/customer/**`
- `/api/system/student/**`
- `/api/test/**`
- `/ws/ssh`

即时聊天的 `/api/sys/chat/**`、`/api/chat/group/**` 和 `/ws/message` 进入正式开发
与测试范围。聊天只复用平台管理员用户、文件和一次性 WebSocket Ticket，不与
社区文章、评论、动态、通知或治理表建立耦合。

## 4. 数据库处置

- V015 禁用并脱敏支付、短信、微信和第三方集成。
- V016 记录原清理决策并清理菜单、配置组和示例记录。
- V017 按修订后的保留策略恢复菜单元数据：
  - 服务监控和即时聊天恢复启用。
  - 其余扩展菜单保留但保持隐藏、停用。
  - 不恢复指向旧 Mars 站点的外链菜单。
- V018 恢复五个无密钥集成配置占位，全部为 `enabled=false`、`status=0`。

V016 清除的演示业务记录不重新伪造；表结构、源码、页面和扩展接口仍保留。
阶段 5 的旧数据库与一致性备份继续作为完整历史恢复点。

## 5. 即时聊天建设范围

正式聊天模块至少覆盖：

1. 私聊发送、历史分页、联系人、未读、已读和在线状态。
2. 黑名单双向发送约束。
3. 群创建、成员权限、群资料、群主转让、管理员、禁言和解散。
4. 群消息历史、群未读和已读游标。
5. 图片消息复用现有文件上传，不新增独立文件事实来源。
6. HTTP 负责持久化与权限校验，WebSocket 只负责经过认证的实时投递。
7. DTO 输入校验、JSON 安全序列化、分页上限和资源级成员权限。
8. 独立后端测试、管理端门禁、聊天真实 E2E 和原有社区关键 E2E。

## 6. 验收原则

- 不关闭类型检查、不跳过测试、不扩大 `any`。
- 聊天开发单独提交，不混入数据库名称迁移、Spring Boot 升级或模块删除。
- 每组变更后执行全量 `scripts/verify.ps1`。
- 原有评论、动态、通知和治理 E2E 必须持续通过。
