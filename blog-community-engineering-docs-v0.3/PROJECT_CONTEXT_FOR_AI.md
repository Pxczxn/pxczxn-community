# 博客社区项目 AI 上下文

## 工程与技术基线（必须遵守）

1. 工程代号为 `pxczxn-community`，Java 根包为 `top.pxczxn.community`。
2. 后台工程统一命名为 `pxczxn-admin`，所有新增模块、包名和产品品牌统一使用 `pxczxn`。
3. 后端使用 Java 21、Spring Boot 3.x、MyBatis-Plus、Sa-Token。
4. 用户端使用 Next.js、React、TypeScript、Tailwind CSS；管理端沿用 Vue 3、Vite、TypeScript、Naive UI。
5. MySQL 8.x 是核心业务唯一事实来源。
6. Redis 可用于会话、缓存、限流、计数和锁，但不得作为核心业务唯一存储。
7. 数据库结构使用 `database/migrations` 下的版本化 SQL 管理，不使用 Flyway 或 Liquibase。
8. V1 是模块化单体，不引入 Spring Cloud、MQ、Kubernetes 或强制搜索引擎依赖。

## 项目目标

在 `pxczxn-admin` 基础工程上开发一个“注册即拥有个人博客”的博客社区。平台包含个人博客、团队博客、文章、动态、系列、投稿、共创、互动、发现和治理。

## 不可违反的产品决策

1. 社区用户与 `pxczxn-admin` 后台管理员是两套账号、两套 Token、两套权限体系。
2. 个人博客是用户唯一公开主页，注册时自动创建，每个用户仅一个。
3. 团队博客通过申请创建，角色为 Owner、Admin、Editor、Author。
4. 用户内容默认属于实际作者；博客获得必要发布展示授权。
5. 一篇文章只有一个主记录和一个主要发布博客，转载不得复制正文。
6. 文章正文使用版本表；当前编辑版本和公开版本分开。
7. 默认富文本，高级 Markdown；每篇文章只有一种主内容源。
8. 所有对外可见文章进入审核体系，低风险内容允许自动通过。
9. 分类属于博客；标签由平台统一维护；系列由作者创建并审核。
10. 社交互动优先借鉴抖音逻辑并做博客适配。
11. V1 不收费、不做支付、广告、钱包、提现和创作者收益。
12. 禁止成人、违法及其他高风险内容。
13. Redis 为可选增强，关闭后核心闭环仍需运行。
14. V1 保持单体工程，不引入微服务、复杂消息队列和分库分表。

## 工程结构

```text
pxczxn-system     平台管理员、RBAC、字典、配置和日志
pxczxn-biz        博客社区业务核心
pxczxn-web-api    社区与公开接口
pxczxn-admin-api  平台审核和运营接口
pxczxn-admin         平台管理前端
pxczxn-web   独立用户前端
```

## M1 目标

```text
注册
→ 自动创建个人博客
→ 创建文章
→ 保存版本
→ 提交审核
→ `pxczxn-admin` 后台审核
→ 发布
→ 公开访问博客主页和文章
```

## M1 暂不开发

动态、评论、点赞、收藏、关注、团队博客、投稿、共创、系列、复杂推荐、私信和支付。

## 开发规则

- 修改前先阅读现有 `pxczxn-admin` 代码和依赖。
- 不重复创建 `pxczxn-admin` 已有基础能力。
- Controller 不直接操作 Mapper 或编排复杂事务。
- 权限统一放在权限服务中，不能只依赖前端。
- 每个任务完成后必须编译、启动、调用接口并报告修改文件与遗留问题。
- 不得为了通过编译注释或破坏原有功能。

完整规则见 `README.md` 与 `docs/`。
