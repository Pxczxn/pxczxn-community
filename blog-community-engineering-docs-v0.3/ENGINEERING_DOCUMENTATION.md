# 工程文档摘要

## 技术基线

- 工程代号：`pxczxn-community`
- Java：21
- 后端：基于 `pxczxn-admin` 工程开发，但模块、包名和品牌统一使用 `pxczxn`
- Java 包名：`top.pxczxn.community`
- 数据库：MySQL 8.x
- Redis：可选增强，用于会话、缓存、限流、计数和锁；核心业务以 MySQL 为准
- 数据库变更：版本化 SQL 脚本，不使用 Flyway
- 用户端：Next.js + React + TypeScript + Tailwind CSS
- 管理端：Vue 3 + TypeScript + Vite + Naive UI

## 产品一句话

注册即拥有个人博客的免费内容社区；平台连接个人博客与团队博客，提供文章、动态、系列、投稿、共创、互动、发现和治理能力。

## 核心架构

```text
pxczxn-admin：后台基础与运营管理
pxczxn-biz：博客社区业务核心
pxczxn-web-api：社区和公开 API
pxczxn-admin-api：平台管理 API
pxczxn-admin：管理前端
pxczxn-web：独立用户前端
MySQL：主数据库
Redis：可选增强
Quartz：定时发布与后台任务
```

## 核心模型

```text
社区用户 ≠ 平台管理员
用户 1—1 个人博客
用户 N—N 团队博客
博客 1—N 文章
文章 1—N 版本
文章始终只有一个主要发布博客和一个公开版本
```

## 第一阶段

```text
注册
→ 自动创建个人博客
→ 新建文章
→ 保存正文版本
→ 提交审核
→ 自动或人工审核
→ 发布公开版本
→ 公开博客和文章访问
```

## 已定产品原则

- 默认富文本，高级 Markdown。
- 分类属于博客，标签属于平台，系列由作者创建并审核。
- 对外文章全部进入审核体系，低风险自动通过。
- 评论仅登录用户，支持关系范围控制。
- 社交互动优先参考抖音逻辑并做博客适配。
- 内容归实际作者，转载不复制正文。
- V1 不收费、不做支付和创作者收益。
- 禁止成人、违法和其他高风险内容。
- 品牌名称暂未决定，不阻塞工程开发。
