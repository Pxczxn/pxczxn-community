# M6-T005 公网灰度运行清单

灰度阶段将 `PXCZXN_CANARY_MAX_REGISTERED_USERS` 设为明确的正整数（首次建议 100）。注册闸门在同一应用实例内串行检查 `community_user` 总数；达到上限后公开注册接口返回 429，不创建部分用户或博客记录。将该值设为 `0` 才表示正式开放；`PXCZXN_CANARY_REGISTRATION_ENABLED=false` 可立即暂停注册。

发布节奏：运营与开发先完成内部个人测试；邀请一小批用户；连续观察一个完整业务日的错误率、审核积压、通知积压和登录异常；修复问题后才扩大名额。每一轮扩大前必须执行生产健康检查、备份验证、监控告警测试和回滚演练。

回退条件包括持续 5xx、认证/发布数据异常、严重审核积压或备份恢复失败。先将注册开关关闭，再使用 `deploy/ops/rollback-release.sh` 回退应用；数据迁移异常按 M6-T003 从经过校验的恢复点恢复，不修改迁移历史。
