> 更新日期：2026-07-31。生产发布采用原生 systemd/Nginx/MinIO，不使用 Docker；GitHub 自动发布按用户选择不启用。

## 已通过的技术验收

- 本机完整门禁已覆盖后端 Maven、博客端和管理端的 typecheck、lint、测试与构建、迁移清单与安全检查、真实浏览器 E2E；当前数据库迁移为 V001–V043，迁移与 verify 文件一一匹配。
- 生产主机已验证域名、HTTPS、Nginx、Spring Boot、React 服务、MySQL、受密码保护的本地 Redis 与私有 MinIO；业务服务、数据服务和监控服务均只在需要的地址监听。
- 原生发布包包含后端 JAR、React 运行时依赖、管理端静态文件和 SHA-256 清单。部署脚本会校验清单、切换三个组件并进行健康检查；隔离成功演练与健康检查失败自动恢复演练均已通过。
- 一致回滚脚本会同时回退后端、React 服务和管理端静态资源，绝不回退数据库；隔离成功回滚和失败恢复演练均已通过。
- 原生每日备份已覆盖 MySQL 与私有 MinIO。已在隔离临时数据库恢复并验证全部 43 条迁移历史；另以非空临时对象验证备份、SHA-256 校验、隔离 MinIO 桶恢复与内容比对，测试对象均已清理。
- Prometheus、Alertmanager、MySQL/Redis/Node exporter 均仅回环监听。飞书 Webhook 存储于主机受限文件，经本地 relay 转换；已向 Alertmanager 注入自动恢复的受控测试告警并收到飞书接口成功响应。
- 已退役未被 Nginx 引用的旧博客后端服务，星语的内网和公网健康检查在退役后保持通过。
