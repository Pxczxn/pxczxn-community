# ADR-0003：品牌名称采用“星语社区”

## 状态

已接受，2026-07-25。

## 决策

- 中文品牌名称统一为“星语社区”。
- 工程代号、Maven 坐标、Java 包名和配置前缀继续使用 `pxczxn`，避免品牌文案
  变化影响稳定技术标识。
- 博客端页面标题、SEO、社交分享图和可见文案使用“星语社区”。
- 管理端保留“pxczxn 运营中心”，表示内部运营产品，不与用户侧品牌混用。

## 影响

工程文档中原有“品牌待定”只保留为历史背景；后续页面、邮件模板、协议和部署
配置不得再使用“墨语社区”等旧名称。英文名称、正式 Logo 和正式域名仍可在
公开运营前单独决定。
