# M2 社区互动任务拆分

## 目标

把博客端原型中的动态、喜欢、收藏、关注、粉丝和通知从演示数据替换为真实
MySQL 关系与社区 API，同时保持无 Redis 也可运行。

## 任务

| 编号 | 任务 | 状态 | 主要验收 |
| --- | --- | --- | --- |
| M2-T001 | 社区互动数据结构 | 完成 | 关注、互动、收藏夹、评论和动态迁移可重复执行 |

## 顺序

```text
T001 → T002 → T003 → T004 → T005 → T006 → T007 → T008 → T009 → T010
```

M2 完成状态：`10 / 10`。

## 共同完成定义

- 社区关系以 MySQL 为最终依据，Redis 仅可作为缓存。
- 点赞、收藏、关注、通知生成和传播操作幂等。
- 计数缓存与关系表在同一事务保持一致，并可通过校准查询恢复。
- 受限内容的互动和转发不会扩大原内容的访问范围。
- 默认私密的喜欢与收藏夹不会公开泄漏名称或结构。
- 管理员和社区用户继续使用两套 Token 与权限边界。
