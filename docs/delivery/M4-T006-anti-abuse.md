# M4-T006 反滥用能力交付记录

状态：完成

## 已交付能力

- 新增 V035：`community_abuse_window` 保存按主体和动作划分的时间窗口，`community_abuse_event` 记录每一次允许或拒绝决定；事件表禁止更新和删除。
- 注册、登录同时按规范化邮箱和直连 IP 限制。仅使用 servlet 的 `remoteAddr`，不信任可由客户端伪造的转发请求头。
- 评论、回复、动态发布、私聊、点赞、收藏和关注只在创建新关系时计入阈值；幂等重试不消耗互动配额。
- 对评论和动态计算 NFKC 规范化后的 SHA-256 指纹。相同用户、相同内容类型在十分钟内的再次提交会被拒绝，正文不会写入反滥用数据表。
- 举报同时限制举报人总量和同一目标的集中举报量。
- 反滥用窗口与审计事件使用独立事务；业务操作失败或被拒绝时，拒绝决定仍保留，业务写入仍由外层事务回滚。
